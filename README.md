RTL Engineering Lab

About This Repository

RTL Engineering Lab is a learning repository focused on digital hardware design and VLSI fundamentals using Verilog HDL.

This project documents my progress in RTL coding, functional simulation, synthesis, timing libraries, logic optimization, gate-level simulation, and hardware coding techniques.

The repository contains learning notes, Verilog examples, testbench exercises, simulation results, and synthesis experiments.

Workshop Topics

1. Digital Design and Synthesis Fundamentals
2. Cell Libraries and Sequential Design
3. Hardware Logic Optimization
4. Netlist Verification Techniques
5. Advanced RTL Coding Practices

Tools and Technologies

- Verilog HDL
- Icarus Verilog
- GTKWave
- Yosys
- Git and GitHub
- Linux

Learning Objectives

- Understand RTL design methodology.
- Develop Verilog coding skills.
- Simulate and verify digital circuits.
- Understand synthesis and netlist generation.
- Explore standard-cell libraries.
- Learn logic optimization techniques.
- Develop a foundation in VLSI design.

Conclusion

This repository is a practical record of my learning journey in RTL design and VLSI. It will be updated with design examples, simulation experiments, synthesis results, and technical documentation.

Focus Areas: RTL Design | Verilog HDL | Simulation | Synthesis | VLSI Fundamentals
