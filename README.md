# MY_RTL_WORKSHOP
RTL Design and Verification Workshop

📌 Introduction

This repository contains my practical work and learning journey in RTL Design and Verification. The workshop focuses on digital circuit design using Verilog HDL, functional simulation, waveform analysis, logic synthesis, and gate-level verification.

The repository is organized into individual sessions, with technical explanations, source code, simulation results, and screenshots documenting the experiments.

🎯 Objectives

- Understand RTL design methodologies.
- Develop digital circuits using Verilog HDL.
- Write and execute testbenches.
- Analyze simulation waveforms using GTKWave.
- Perform logic synthesis using Yosys.
- Explore standard-cell libraries and timing information.
- Understand logic optimization and technology mapping.
- Compare RTL simulation with synthesized circuit behavior.

🛠️ Tools and Technologies

Tool| Purpose
Verilog HDL| Hardware description and RTL coding
Icarus Verilog| Verilog compilation and simulation
GTKWave| Simulation waveform analysis
Yosys| Logic synthesis and optimization
SKY130| Open-source standard-cell library
Linux| Development environment
Git and GitHub| Version control and project documentation

🔄 RTL Design Flow

The general workflow followed in the workshop is:

Design Specification → RTL Coding → Testbench Creation → Functional Simulation → Waveform Analysis → Logic Synthesis → Gate-Level Verification

📚 Workshop Sessions

Day 1 – RTL Design Fundamentals

- Introduction to RTL design
- Verilog modules and testbenches
- 2:1 multiplexer implementation
- Simulation and waveform inspection
- Introduction to synthesis

Day 2 – Timing Libraries and Sequential Circuits

- Standard-cell timing libraries
- Liberty (".lib") file analysis
- Flip-flop design and verification
- Reset and set behavior
- Technology mapping

Day 3 – Logic Optimization

- Boolean logic simplification
- Constant propagation
- Redundant logic removal
- Counter optimization
- Synthesis report analysis

Day 4 – Multiplexer Design and Verification

- Multiplexer implementation
- RTL simulation
- Gate-level netlist generation
- Functional comparison and debugging

Day 5 – RTL Coding Styles

- IF-ELSE and CASE statements
- Latch inference
- Sequential and combinational coding
- Looping constructs
- Synthesis and waveform analysis
