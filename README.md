RTL Design Workshop

«Practical learning in Verilog RTL design, simulation, synthesis, optimization, and VLSI physical design.»

Overview

This repository documents my learning and practical work in RTL Design and VLSI Physical Design. It covers Verilog HDL coding, functional verification, logic synthesis, timing concepts, and the ASIC physical design flow using open-source EDA tools.

Objectives

- Learn Verilog HDL and RTL design.
- Develop digital circuits and testbenches.
- Perform RTL simulation and waveform analysis.
- Understand logic synthesis and optimization.
- Explore timing analysis and standard-cell libraries.
- Study the ASIC physical design flow.
- Learn floorplanning, placement, clock tree synthesis, routing, and sign-off.

RTL Design Modules

Module 0 — Workshop Introduction

Introduction to RTL design, the digital design flow, and the required tools.

Module 1 — RTL Design and Synthesis

Verilog basics, combinational logic, simulation, and testbench development.

Module 2 — Timing Libraries and Flip-Flops

Standard-cell library concepts, timing fundamentals, and sequential logic.

Module 3 — RTL and Logic Optimization

Boolean simplification, combinational logic optimization, and synthesis concepts.

Module 4 — RTL and Gate-Level Verification

Blocking and non-blocking assignments, simulation mismatches, and verification concepts.

Module 5 — Advanced RTL Coding

Optimization techniques, multiplexers, demultiplexers, and ripple carry adders.

Physical Design Modules

PD-Module-1 — Physical Design Flow

Overview of the ASIC implementation process, from synthesized netlist to physical layout.

PD-Module-2 — Chip Floorplanning and Power Integrity

Floorplanning, core utilization, power distribution, and power integrity concepts.

PD-Module-3 — CMOS Technology and Standard-Cell Design

CMOS inverter design, characterization, standard-cell layout, and fabrication fundamentals.

PD-Module-4 — Timing Analysis and Clock Tree Synthesis

Timing concepts, clock distribution, clock skew, and physical design optimization.

PD-Module-5 — Routing and Physical Verification

Routing, design rule checking, parasitic extraction, and physical verification concepts.
