Classwork

Overview

This section contains practical exercises completed during the RTL Design Workshop. It focuses on applying Verilog HDL concepts through coding, simulation, and verification.

Topics Covered

- Combinational logic design
- Sequential logic design
- Verilog module development
- Testbench creation
- RTL simulation and waveform analysis
- Logic synthesis and optimization

Practical Exercises

Exercise 1: Combinational Circuits

Design and simulate basic combinational circuits such as multiplexers and logic gates.

Exercise 2: Sequential Circuits

Implement and verify sequential circuits such as D flip-flops.

Exercise 3: Arithmetic Circuits

Design and simulate arithmetic circuits such as adders.

Exercise 4: Functional Verification

Develop testbenches to verify circuit functionality across different input combinations.

Tools Used

- Verilog HDL
- Icarus Verilog
- GTKWave
- Yosys

Learning Outcome

The classwork section provides practical experience in RTL coding, simulation, debugging, and basic synthesis analysis.
